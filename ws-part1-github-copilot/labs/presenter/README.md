
If activation is blocked, use the virtual environment executable by its absolute
path throughout; avoid changing execution policy. The solution tests deliberately
read the shared fixtures from `starter/data`; run them here, not after copying
the test module alone into an attendee repository.

The starter should have two passing tests and display 118.75. The reference
solution should pass all its tests and display 158.33 for normal data and 0.00 for
header-only data. The validator checks a clean starter copy, reference CLI
examples, Python syntax and local file links. It does not check portal features,
Markdown anchor correctness or actual customization discovery. The copy check
uses GH2's explicit file list, excluding any presenter's local Git history or caches.

Run the starter and solution pytest commands in their **own directories** as
shown. Both modules are named `summarize.py`; collecting both suites in one
pytest process can import the wrong module. A missing `pytest` error means the
selected interpreter needs `starter/requirements-dev.txt`, not a code change.
